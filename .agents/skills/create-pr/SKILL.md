# Create PR

## Workflow

1. Inspect all commits and diffs that will land in the PR.
2. Capture why the change exists, not just what changed.
3. Draft a concise title and body oriented around intent, changes, and major decisions.
4. Create the PR only after the user explicitly asks for it.

## Writing Rules

- Prefer Korean prose for the body in this repo.
- Omit decisions if there were no meaningful tradeoffs.
- Mention linked issues when relevant.
