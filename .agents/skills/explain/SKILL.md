# Explain

## Workflow

1. Start from the user's actual question.
2. Read the smallest relevant set of files needed for a trustworthy explanation.
3. Explain in execution order or dependency order, whichever reduces confusion.
4. Prefer intent, boundaries, and data flow over line-by-line narration.
