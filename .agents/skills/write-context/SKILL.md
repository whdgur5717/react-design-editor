# Write Context

## Goal

Create or update `CONTEXT.md` in the current folder so an agent can understand the module without rereading the entire codebase.

## Required Contents

1. What the module does
2. File structure and roles
3. Core design decisions
4. Usage patterns
5. Extension considerations

## Writing Rules

- Focus on intent and context, not implementation trivia.
- Keep it concise and readable without reading source code first.
