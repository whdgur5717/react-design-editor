# Product Definition

## Why it exists

Design tools like Figma create a gap: you design something, then need a separate process to turn it into code. That translation step, whether manual or AI-assisted, loses intent and adds unnecessary handoff.

This editor eliminates that gap. The editor renders real React components, so what you see is the code.

## Vision

Replace Figma with a design editor whose output is production React code, with no intermediary translation step.

## Target User

Anyone who uses a design editor. In this product, the person designing the UI is the same person shipping the code.

## User Pain Points

- Design-to-code workflows lose intent during translation
- AI-assisted design-to-code adds an unnecessary dependency
- Current workflows have too many handoff points

## Core Value Proposition

Design = Code. The editor renders real React components, so there is no conversion step between designing and shipping.
