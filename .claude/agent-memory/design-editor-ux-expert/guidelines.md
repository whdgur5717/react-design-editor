# 디자인 가이드라인

## 핵심 원칙

> PM-Designer 합의 (2026-03-05). 원문: `docs/plans/2026-03-05-design-concept.md`

1. **코드 동시성 (Code Co-presence)** — 코드가 별도 모드가 아니라 디자인과 항상 공존. 모드 전환이 아닌 하나의 워크스페이스.
2. **친숙함** — Figma/VS Code 사용자가 바로 적응할 수 있는 UI 패턴. 레이아웃 뼈대는 업계 표준.
3. **코드 의식적 디자인** — CSS 속성 직접 노출, 컴포넌트 트리 기반 레이어 패널.
4. **경량함** — DOM 기반 특성을 살린 깔끔하고 가벼운 느낌.
5. **Craft over Feature** — 기능 수보다 각 기능의 인터랙션 완성도 우선. 프로토타입 수준 UI(유니코드 아이콘, 이모지) 지양.

## Figma 클론 방지 — 차별화 3축

- 하이브리드 라이트/다크 테마 (UI 라이트 + 코드 영역 다크)
- Warm Amber 액센트 (경쟁 도구의 Blue-Purple 대역과 차별화)
- 코드 동시성 UI (속성 패널 듀얼 뷰, 인라인 코드 힌트, 태그 표기)
